Every node is one node of a blacksmith document, the SDK's own model, and a wire carries what it makes; a list wired into a node runs it once per item. Drag a wire onto the canvas for the nodes that fit, right-click for any node, drag a slider and the part follows; Alt+click a pin to break its wires, Home to fit. Save, open or share the document (a .json file the SDK's Document reads), open a CAD file as held bodies, or export it as a Python or JavaScript script that makes the same part. Nothing is uploaded.

This page needs WebGL2, module workers and WebAssembly. The notebook may still work here.
